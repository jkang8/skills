Build a settings page for a team workspace app in this repo's `web/` (React + TypeScript + Tailwind v4). Sections: profile (name, email), notifications (three toggles), and API keys (list with created date and last used, create and revoke). Use the components in `web/src/components/ui/` and add any you need there. Put the page at `web/src/routes/settings.tsx`. Write the files only: don't install dependencies or start a server.
