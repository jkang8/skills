Build the home dashboard for a B2B billing app in this repo's `web/` (React + TypeScript + Tailwind v4). It shows monthly recurring revenue, active customers, churn rate, and a table of the 20 most recent invoices (customer, amount, status, due date) that can be filtered by status. Data comes from `GET /api/dashboard`; mock it with a typed fetch function. Put the page at `web/src/routes/dashboard.tsx`. Write the files only: don't install dependencies or start a server.
