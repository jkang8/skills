Record this decision for the repo as a decision record in `docs/decisions/`. Notes from the team: we spent two meetings on this. At first Priya wanted to add pandas so we could get median and percentiles for free, and we even had a branch with it, but the install got heavy (numpy and friends) and the CLI started taking about a second to launch. Sam pointed out that our users run it in CI containers where installs are slow. We looked at polars too but same problem. In the end we decided csvstats stays stdlib-only: no third-party runtime dependencies. If we need percentiles we'll use statistics.quantiles. Dev-only tools like pytest are fine.
